# Evidence claims

A claim record bounds rather than proves a claim. Regression success cannot be
used as fresh support. A claim becomes stale outside its registered versions
and preserves known counterevidence.

`supported_within_scope` records must name a registered distribution,
benchmark version, and implementation version. `contradicted` records name
counterevidence; historical `stale` records name their benchmark and
implementation versions. `verify-claim.sh` checks exact claim, registration,
and result roles plus their declared v1 links. Verified links do not establish
evidentiary sufficiency or justify a supported status.
